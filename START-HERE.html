  1. 在电脑上打开 Edge 或 Chrome，点一下顶部地址栏。

能打开 Firmware Config 页面，并且构建版本是 2.0.0-paxx12-24，才算完成。见页面说明。

打不开时依次检查：IP 是否变了、Wi-Fi 是否连着、Advanced Mode 是否开启。

  • 向导要的是 SSH 密码，不是 Wi-Fi 密码，也不是 Snapmaker 账号密码。
  • 没改过的话，用户名是 root，初始密码是 snapmaker。见上游凭据说明。

  3. 确认是 ACE Pro 第一代，不是 ACE 2 Pro。
  4. 关闭两台设备的电源，按 SnapAce 硬件指南接好专用 USB 线和四路料管，再开机。普通充电线不能代替。
  5. 让电脑和 U1 连同一个网络，两者都要能上网。

U1 有自己改过的配置时，先另存备份；本项目的备份不保护固件升级前的改动。

型号、接线、屏幕操作不熟悉，先看安装前准备。

2. 下载、解压、启动

  1. 下载安装包。
  2. 在“下载”文件夹里右键这个压缩文件，点 全部解压缩。
  3. 打开解压出的 Ultimate-U1-ACE-link 文件夹，双击 START-HERE.cmd。
  4. 输入 1 选中文，按回车。

不要在压缩包预览窗口里直接运行。.html 文件是离线说明，不是安装程序。

第一次安装会自动进入这一步。

  1. 选自动检查。
  2. 等向导下载并校验固件，核对 ACE 的型号、当前版本和空闲状态。
  3. 核对窗口显示的源版本和目标版本，再确认更新。
  4. 出结果之前，不要断电，不要拔 USB。

只支持从 V1.3.856／引导 V1.0.1 升级到 OpenCubic CFW 1.1.1（显示 CV1.3.863）。

6. 核对管路长度，再安装

必须确认

安装器不能测量实际管长。示例数值不是通用参数，不要直接照抄。

第一次安装会问两个长度，已有安装保留原值。

字母含义
A退料时 ACE 回抽的距离。退完后耗材尖端要留在 ACE 后方的料管里。
B进料时快速送料的距离。要在到达打印头之前结束，并且小于 A。
  1. 按参数与校准测量自己的管路，选出 A 和 B。
  2. 核对窗口列出的设置，确认安装。

已测机器用的是 A = 1250 mm、B = 1150 mm，仅供对照。

安装器会备份要改的文件，并自动把 Filament Detection 设为 External。

等窗口明确提示本项目安装成功。只提示 ACE 固件成功不算。

  1. 向一个空的 ACE 入口插入耗材，手离开滚筒，等它咬料并读完 NFC。
  2. 确认它没有自己一路送到打印头，材料信息正确。没识别的可手动填写。
  3. 在 U1 上点 进料，等完成。
  4. 点 退料，确认耗材留在 ACE 里，材料信息还在。
  5. 不拔耗材，再点一次 进料。
  6. 这一槽通过后，其余三槽一次测一槽。

U1 固件与访问设置

准备 U1 固件

English · 新手向导 · 手动安装入口

向导会下载准确的 U1 扩展固件（上游原版文件），校验后复制到 U 盘。然后你在 U1 屏幕上完成更新，并打开 Advanced Mode 和 Root Access。

这一步不刷写 ACE。ACE 固件步骤在同一个向导里随后进行。

必须确认

首次固件更新必须在 U1 屏幕上确认。

远程安装前，还必须在屏幕上打开 Advanced Mode 和 Root Access。

准备什么

  • 能联网的 Windows 10 或 Windows 11 电脑，以及已完整解压的本项目安装包。
  • 一个已经是 FAT32 格式的可移动 U 盘，至少空闲 300 MB。向导不格式化磁盘。
  • 空闲并已冷却的 U1：打印和全部耗材动作已结束，加热和 ACE 烘干已关闭，喷嘴和热床低于 50℃。
  • 第一次安装时：用正常退料操作退出四个打印头里的耗材，取出四个 ACE 入口的耗材，然后再次等待加热器冷却。只是更新本项目时，不要求清空入口。
  • 已有自定义配置时，在固件更新前自己保存一份备份。本项目稍后的安装备份保护不了它。

U1 已经是准确的支持版本时，改选菜单 1. U1 已准备好。有其他自定义固件或较新版本时，不要为了通过安装检查就直接覆盖。

向导步骤

  1. 完整解压项目压缩包。双击 START-HERE.cmd，选择语言，再选择 2. 准备 U1 固件 U 盘。
  2. 把 FAT32 U 盘插入电脑。在列表中选择它，核对盘符、名称和容量，然后确认。
  3. 等待下载、SHA-256 校验、复制和复制后校验全部完成，然后在 Windows 中弹出 U 盘。
  4. 把 U 盘插入 U1。在 U1 屏幕点 设置 → 关于 → 固件版本 → 本地更新。
  5. 选择 U1_extended_2.0.0-paxx12-24_upgrade.bin，确认更新。等待更新完成并重启，期间保持供电。
  6. 点 设置 → 维护 → Advanced Mode，开启并按要求完成重启。
  7. 点 设置 → 维护 → Root Access，阅读提示，向下滚动点 Agree / 同意，设为 Open。
  8. 检查 Wi-Fi，必要时重连，记下现在显示的打印机 IP 地址。
  9. 回到电脑上的同一个向导继续。它会询问打印机地址和 SSH 密码。

向导不会覆盖名称相同但内容不同的文件。先自己检查该文件，再重试。找不到合适的盘时，换用 FAT32 可移动 U 盘。不要改程序强制选择其他磁盘。

U1 更新失败时，保存屏幕显示的报错原文，按 Snapmaker 固件更新故障说明处理。不要尝试随机固件文件。主机适配的回退不能撤销 U1 固件更新。

参数与校准

English · 新手安装向导

进料和退料由三个长度控制。四个槽共用这三个长度和速度设置，所以四条管路都要检查。

长度单位是毫米 mm。速度是请求值，单位 mm/s，不是实测的线材速度。

记号设置文件中的名称作用仅供对照的参考值

1250／1150／300 是一套已测试装置的参考值，不是通用值。

进料在 U1 喷头传感器检测到线材时停止，不会故意一直顶到堵转。

进料不成功时，由最大行程和超时限制停止。

  • C 为 0–500 mm，且小于 A 和 B。
  • B 不大于 A，并小于 2500 mm 的进料上限。
  • 快速段速度不超过 200，慢速段和消松回送速度不超过 50。

A、B、C 如何一起工作

把线材插入 ACE，只会触发短距离咬料和 NFC 读取。在 U1 上选择“进料”后，才会长距离送料。

有可靠的起始位置记录时，程序这样计算：


本次快速段 = max(0, B − 已记录的回送量)
本次慢速段最大余量 = 2500 − 本次快速段
  • 两段中任何时候，喷头传感器都可以提前停止送料。慢速段速度为 50，余量是上限，不是目标。
  • B = 1150、C = 300 并成功退料后，快速段为 850 mm。程序会自己减去已记录的 C。C = 300 时，不要把 B 填成 850 来抵消。 那样快速段会变成 550 mm。
  • 重启、动作中断或位置不确定后，不使用快速段。这时第一次进料较慢是正常的。

退料：U1 释放热端，ACE 按速度 80 回抽 A，C 启用时再按速度 50 送 C，并记录 C 供下一次进料使用。

退料后，线材必须仍留在 ACE 入口和后方 PTFE 管内，U1 喷头传感器必须为空。

校准 PTFE 管路

测量四条管路

  1. 结束打印和所有进退料动作，等打印机冷却。拆管或拔接硬件前先断电。
  2. 给每根管的两端标上 ACE 槽号和 U1 喷头号。
  3. 沿安装后的弯曲路线量每根管，不要量直线距离。量不到的部分记为“未知”，不要当成 0。
  4. 选定退料后尖端的停留点：靠近 ACE 一侧的 PTFE 管内。尖端不能到达喷头，也不能退出 ACE 入口。
  5. 把所有料管重新接牢，再做通电测试。
  • 软尺量不到 ACE 内部路径、初始咬入量、喷头内部路径和热端退料动作。测量只用来判断余量。
  • 按到喷头的最短路径检查 B。参考值 A 和 B 相差 100 mm。这不代表你的机器也有 100 mm 的余量。
  • 如果四条路径找不到安全的共用参数，先调整管路布局。

选择并测试 A 和 B

  1. 这套管路已有正常工作的记录时，从记录的参数开始。先查清未知的尺寸，再填长回抽值。向导可以中途退出，不安装。
  2. 把 C 设为 0。保持快速段速度 200、接近速度 50、退料速度 80。
  3. B 选得短一些，保证到喷头前还有慢速接近段。A 要让尖端退回到停留点。
  4. 在向导里填写 A 和 B（首次安装），或按应用新参数操作。
  5. 在一个槽上，在 U1 依次点进料、退料、再进料。每个动作完成后再点下一个。
  6. 运动停止后，检查尖端位置、喷头传感器、ACE 入口和松出的线材。滚筒转动时手不要靠近。拆管前先断电。
  7. 用同一组参数在另外三个槽上重复，然后才正常打印。结果记在验收清单里。

调整

  • 还在快速段，线材就到了喷头：减小 B。传感器能停下，不代表余量足够。
  • 退料后尖端太靠近 U1 一侧，喷头为空，没有报错：在 ACE 一侧余量内小幅增加 A。保持 C = 0 重测。
  • 尖端退出 ACE 入口：先恢复正确的物理状态，再减小 A。不要重复点“退料”来补救。
  • 退料失败、喷头仍检测到线材、打滑或卡住：停止。检查热端释放和管路。不要盲目加大 A。
  • 每次只改一个长度，幅度不超过你能确认的余量。换管或重新走管后，把 C 设为 0，重做本节。不要用旧参数去试新管是不是太短。
  • 其他现象见故障排查。

启用消松回送

C 在 A 之后按设定长度往 U1 方向送一段。它没有张力传感器。

C = 0 时四个槽的进料、退料、再进料都通过后，才能启用 C。

  1. 观察退料后松出的线材。
  2. 按看到的松量和到喷头的余量，选一个有限的 C。已测的 C = 300（第 4 槽记录）不是给你的推荐值。
  3. forward_takeup_speed 保持不超过 50。
  4. 应用参数，测试一次正常退料。喷头必须仍为空，ACE 入口必须仍有料。
  5. 不拔出线材，再进料一次。
  6. 在四个槽上重复这些检查。
  • C 越大，停留的尖端离喷头越近。线材过紧、卡住或到达喷头时，停止，减小 C 或设为 0。
  • 仍有松圈时，先确认线材移动顺畅。不要为了抵消过大的 C 而加大 A。

识别流程

  1. 耗材 NFC 标签
  2. ACE 读取并解码
  3. U1 查询并转换结果
  4. 显示并保存耗材信息

多品牌解码来自 OpenCubic。U1 内置 OpenRFID 是另一条独立路径。

  1. ACE 的读卡器读取标签，ACE 固件完成解码。
  2. 运行在 U1 上的适配程序向 ACE 查询，取得该槽已解码的品牌、类型和颜色。
  3. 适配程序转换名称和颜色格式，再写入 U1。例如 Bambu Lab／PLA Matte 变成 Bambu／PLA／Matte。品牌为空时显示 Generic。

U1 内置读卡器是另一套读卡器，本方案不使用。安装器会设置 External 并停止 U1 的 OpenRFID 服务。

检查 External 模式

  1. 打开打印机的 /firmware-config/ 页面。
  2. 找到 Snapmaker Components。
  3. 查看 Filament Detection，选中值必须是 External。保留的旧版 v0.1.0 安装包不会自动设置，需要手动选择 External。
重要警示

使用本项目连接 ACE 时，请保持 External。

不要为了改善 ACE 识别而启用内置 OpenRFID。

这样会启用另一条读卡路径，可能干扰 ACE 的材料信息处理。

检查识别结果

  1. 向一个空的 ACE 入口插入耗材，手远离滚筒。
  2. 等待短咬料和 NFC 识别结束。
  3. 在 U1 上打开该槽的耗材详情，对照料卷检查。
  • 耗材停在 ACE 处等待。插入耗材不会自动送到打印头。
  • 多个槽接连变化时，识别可能更久。识别期间不要反复点进料。
  • 只要 ACE 入口仍有耗材，进料和退料都会保留材料信息。
  • 确认入口为空后，该槽的信息才会清除。未知状态或断连状态不会清除。

本页命令在 Windows PowerShell 里运行，不需要以前的窗口还开着。

  • ACE 固件维护和 U1 主机适配安装是两个独立的事务。
  • 主机备份不能回退 ACE 或 U1 固件。

1. 新开窗口并连接

  1. 点击“开始”，搜索并打开 Windows PowerShell。
  2. 准备 U1 屏幕当前的 IP 和记录的 RemoteDir。安装目录名含 stage，手动调参目录名含 tuning。向导失败时会显示该目录，电脑私人日志里也记有 Remote stage。
  3. 粘贴下面整块。先输入 IP 和 SSH 密码，再粘贴记录的完整目录。
  4. 首次连接的身份核对和隐藏密码输入，见确认连接。

不要猜目录。 找不到记录时，保留错误窗口、屏幕信息和文件。不要用一个只是看起来最新的目录执行写入。


$ErrorActionPreference = 'Stop'
Get-Command ssh.exe, scp.exe -CommandType Application | Out-Host
$PrinterAddress = (Read-Host '输入 U1 屏幕 Wi-Fi 页显示的 IPv4 地址').Trim()
if ($PrinterAddress -notmatch '^(?:[0-9]{1,3}\.){3}[0-9]{1,3}$' -or
    @($PrinterAddress.Split('.') | Where-Object { [int]$_ -gt 255 }).Count -gt 0) {
    throw 'STOP: Invalid IPv4 address'
}
$PrinterTarget = 'root@' + $PrinterAddress
ssh.exe $PrinterTarget 'id'
if ($LASTEXITCODE -ne 0) { throw 'STOP: SSH connection failed' }
$RemoteDir = (Read-Host '粘贴上次记录的 RemoteDir 路径').Trim()
if ($RemoteDir -notmatch '^/userdata/ultimate-u1-ace-(?:stage|tuning)-[0-9]{8}-[0-9]{6}(?:-[a-f0-9]{8})?$') {
    throw 'STOP: Use the exact recorded staging directory'
}
ssh.exe $PrinterTarget "ls '$RemoteDir/installer.py' '$RemoteDir/manifest.json' '$RemoteDir/tools/ace_usb/wizard_backend.py'"
if ($LASTEXITCODE -ne 0) { throw 'STOP: Recorded package files are unavailable' }

期望： 显示 uid=0(root) 和三个文件路径。

目录或文件不存在时，不要从其它版本拼文件。先确认原事务的结果，再上传替换包或开始任何写入。

先读 ACE 状态，再读主机状态

这条查询不会打开串口、恢复服务或启动刷写：


ssh.exe $PrinterTarget "cd '$RemoteDir' && python3 tools/ace_usb/wizard_backend.py result --wait-seconds 30"
if ($LASTEXITCODE -ne 0) { throw 'STOP: ACE result query failed' }
ACE 结果怎么做
PREPARING、STARTING、RUNNING、RECOVERING保持供电，稍后重复同一条 result 查询。
NEEDS_ATTENTION、ERROR 或查询失败转到 ACE 中断处理。不要因为读不到 Klipper 就重启或回退。
NONE没有 ACE 事务。

安全终态还必须有 ready: true 和 service_restored: true。

只有在没有未决 ACE 事务时，才读取主机状态：


ssh.exe $PrinterTarget "cd '$RemoteDir' && python3 installer.py status"
if ($LASTEXITCODE -ne 0) { throw 'STOP: Host status is unavailable; do not start a write' }
  • 期望 klipper_state: ready。安装后 managed 为 true。
  • ace_version 是本项目的模块版本，不是 ACE 固件版本。
  • status 读取的是当前状态。它不能证明失联的安装程序已经结束，也不能证明那次安装成功。
  • 原进程可能还在运行时，继续等待并保留记录。不要回退，也不要再次安装。

2. ACE 固件操作中断

最简单的路径： 解压同一版本的安装包，运行 START-HERE.cmd，选择 菜单 4：ACE 固件。

它先读取保存的事务，不会自动重刷。

只有在任何写入之前就失败的情况，它才可能提供“检查并恢复服务”。

结果怎么做
正在运行保持 ACE、U1 和 USB 的供电与连接，继续查询。
SUCCEEDED 且服务已恢复核对材料变化。ACE 维护已完成，主机安装另行核对。
FAILED_SAFE解决网络、空闲或冷却条件，再用同一版本安装包重新准备。
NEEDS_ATTENTION 且 flash_attempted: false菜单 4 可提供仅检查的恢复。确认一次，然后等待。

仅检查的恢复要求 NEEDS_ATTENTION、flash_attempted: false，并且后台任务已停止。先确认这三项。

下面的命令只恢复尚未开始写入的维护状态，不更新固件：


$Raw = & ssh.exe $PrinterTarget "cd '$RemoteDir' && python3 tools/ace_usb/wizard_backend.py result"
if ($LASTEXITCODE -ne 0) { throw 'STOP: ACE query failed' }
$SavedAce = ($Raw -join "`n") | ConvertFrom-Json
if ($SavedAce.state -ne 'NEEDS_ATTENTION' -or $SavedAce.flash_attempted -ne $false -or
    $SavedAce.operation -notmatch '^[a-f0-9]{32}$') { throw 'STOP: Probe-only recovery is not available' }
$OperationId = $SavedAce.operation
ssh.exe $PrinterTarget "cd '$RemoteDir' && python3 tools/ace_usb/wizard_backend.py recover --operation $OperationId"
if ($LASTEXITCODE -ne 0) { throw 'STOP: Do not repeat recovery; query its result' }
ssh.exe $PrinterTarget "cd '$RemoteDir' && python3 tools/ace_usb/wizard_backend.py result --operation $OperationId --wait-seconds 30"
if ($LASTEXITCODE -ne 0) { throw 'STOP: Read the saved result later; do not repeat recovery' }

期望的最终结果： CANCELLED_SAFE、ready: true、service_restored: true。

  • RECOVERING：只重复第 1 节的 result 查询，不要重复 recover。
  • 已经尝试过刷写时，后台会拒绝恢复。不要改它的记录。
  • 其它故障可能需要人工维护，普通安装步骤不能保证恢复。见 ACE 技术维护说明。

4. 更新本项目

  1. 完成打印和耗材操作。关闭烘干，把所有加热目标设为零，冷却到 50 °C 以下。
  2. 送料辅助仍在工作时，对该槽正常退料，等动作结束后再次冷却。不需要退空所有槽。
  3. 保存私人配置和备份。下载完整的新安装包，解压到新文件夹。
  4. 向导用户：运行新包的菜单 1。它默认保留现有参数。
  5. 手动用户：从手动安装第 2 步开始，用新窗口和新目录。先检查计划，再安装一次。
  6. 不要把旧 JSON 整份复制到新模板。不要仅为了更新就把 apply_existing_settings 改为 true。有意调整参数见参数说明。

核心文件上的未知改动会被拒绝，不会自动合并。保留这些改动，不要为了绕过检查而覆盖它们。

6. 回退最近一次主机安装

只有原安装程序已结束、没有未决 ACE 事务、机器空闲且已冷却时才使用。

正常回退还要求 ACE 就绪、烘干关闭、送料辅助关闭。不要跳过这些条件。

先按第 1 节连接并查询。确认最近的备份就是要恢复的目标，然后运行一次：


ssh.exe $PrinterTarget "cd '$RemoteDir' && python3 installer.py rollback"
if ($LASTEXITCODE -ne 0) { throw 'STOP: Rollback failed; preserve the error' }
  • 期望 rolled_back: true 和备份编号。然后按第 1 节再次查询状态。
  • 回退到安装本项目之前的状态后，managed: false 和 ace_version: null 可以是正常的。
  • 安装后被手工改过的文件会导致拒绝，这是为了保护后来的改动。不要盲目删除这些文件。

7. Klipper 无法就绪时的主机恢复

这不能恢复 ACE 固件，也不能绕过正在进行的打印或未决的 ACE 事务。

只有原安装程序已结束、运动已停止、烘干和加热已关闭、实际温度低于 50 °C 时才使用。

屏幕或独立观察无法确认已冷却、无运动时，停止。网络读不到状态，不能当作设备空闲的证据。

本页不能保证所有固件、文件或硬件故障都能自动恢复。
