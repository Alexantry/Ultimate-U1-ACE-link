一、先确认你手上的设备

需要确认的项目怎么看完成标准
打印机查看机身标识或购买记录。型号是 Snapmaker U1。
送料盒查看 ACE 机身铭牌、包装或购买记录。型号是 ACE Pro 第一代。
电脑使用能连接家庭网络的 Windows 电脑。能打开网页、下载文件和解压安装包。
USB 连接查看下面的硬件准备章节。已有经过核对的 ACE 第一代专用 USB 连接线。
四路料管查看 ACE 到 U1 的实际管路。四路连接明确，管路没有压扁或急弯。

ACE 2 Pro 不属于本项目当前的适用范围。 不要仅凭“四个料槽”判断代际。看不清型号时，先请卖家或设备提供者确认。

OpenCubic 发布页同时列出了 ACE 1 Pro 和 ACE 2 Pro 的不同固件；两者不能混用。

必须确认

任何接线、固件更新或安装之前，先结束打印和全部耗材动作。

关闭加热和 ACE 烘干，等待所有喷嘴和热床低于 50℃。

第一次安装时，先用 U1 的正常退料退出四个打印头，再将四路耗材退出 ACE 入口。

退料可能加热喷嘴；完成后关闭加热并重新等待冷却。

已经使用本项目、只是更新时，不要求清空四路，但仍需空闲、关闭烘干和冷却。

二、在打印机屏幕查看版本

  1. 在 U1 屏幕打开 设置 / Settings。
  2. 点 关于 / About。
  3. 点 固件版本 / Firmware Version。
  4. 记下当前显示的版本。

这个入口也用于后面的本地更新。Snapmaker 官方更新说明

本项目使用的扩展固件版本是 v2.0.0-paxx12-24。

你现在的情况下一步
明确已安装 v2.0.0-paxx12-24，配置网页也能确认该构建版本跳到第四节，检查访问开关。
屏幕只显示 2.0.0，不知道有没有扩展固件不能只凭 2.0.0 判断。先按第四、五节检查现有访问开关和配置网页；能确认准确构建就不必重复升级。
使用其他扩展版本或自己修改过的系统先保留原配置，再按对应维护流程迁移；不要为了安装本项目直接覆盖。

主安装向导会再次核对版本。固件文件可以由向导准备，U1 仍在屏幕确认后执行本地升级。

三、还没有正确的 U1 扩展固件时

如果已有自定义配置或改过系统文件，先把它们保存到电脑的私人备份目录，并保留原文件位置的记录。

本项目不提供整台 U1 的系统镜像备份；只保存配置网页截图也不能备份自改文件。

不知道现有系统改过什么或如何恢复时，先核对原安装记录，再决定迁移步骤。

后面的主安装备份不能保护这一步升级之前的系统修改。

如果已经选择向导菜单 2，由向导完成下载、校验和复制。直接跟随窗口操作，不需要重复下面的手动下载步骤。

1. 下载正确的文件

  1. 在电脑浏览器打开 v2.0.0-paxx12-24 发布页。
  2. 确认页面标题包含 v2.0.0-paxx12-24。
  3. 向下找到 Assets，必要时点开它。
  4. 下载 U1_extended_2.0.0-paxx12-24_upgrade.bin。

你会看到： 电脑下载文件夹中出现一个以 .bin 结尾的文件。

不要下载 Source code 作为打印机升级文件，也不要选择 rolling 预发布版本。本项目要求上述准确版本。

2. 校验下载文件

SHA-256 用于检查文件是否与本项目固定的上游文件完全一致。手动下载时也要检查。

  1. 在“下载”文件夹中，按住 Shift，右键刚下载的 .bin 文件。
  2. 点 复制文件地址／复制为路径。
  3. 按 Windows 键 + R，输入 powershell，按回车。
  4. 复制下面这一行到打开的窗口，按回车。
  5. 出现 Paste the file path 时，粘贴刚复制的文件路径，再按回车。

Get-FileHash -Algorithm SHA256 -LiteralPath ((Read-Host "Paste the file path").Trim('"'))

把结果中的完整 Hash 值与下面比较，字母大小写不影响结果：


42dcf59e06ef0f6fab20745883322f24ddd3c1a09da07449b356dd9dab943070

不一致就不要安装。 从准确的上游链接重新下载后再检查。

文件身份和来源见 U1 固件准备说明。

3. 准备 FAT32 格式的 U 盘

  1. 把 U 盘插入电脑。
  2. 按键盘 Windows 键 + E，打开文件资源管理器。
  3. 点左侧的 此电脑。
  4. 找到刚插入的 U 盘。
  5. 右键该 U 盘，选择 属性。
  6. 查看 文件系统 一项。

完成标准： 文件系统显示 FAT32。已经是 FAT32 时，不要重复格式化。

如果不是 FAT32，可以改用已经准备好的 FAT32 U 盘。需要自行格式化时：

  1. 先把 U 盘中需要的文件复制到电脑。
  2. 再次核对选中的确实是这个 U 盘。
  3. 右键该 U 盘，选择 格式化。
  4. 在 文件系统 中选择 FAT32。
  5. 确认接受清空这个 U 盘后，再点 开始。

格式化会删除所选盘内的数据。 不确定哪个是 U 盘，或列表没有 FAT32 时，先停在这里，请熟悉电脑的人帮助准备。不要选择电脑系统盘或其他硬盘。

4. 把升级文件放到 U 盘

  1. 打开电脑的 下载 文件夹。
  2. 复制刚下载并通过校验的 .bin 文件。
  3. 打开 U 盘。
  4. 直接把文件粘贴到 U 盘第一层，不要放进其他文件夹。
  5. 等待复制完成。
  6. 右键 U 盘，选择 弹出。
  7. 从电脑拔出 U 盘。

“第一层”指双击 U 盘后立即看到的位置，也叫根目录。FAT32 和根目录要求来自扩展固件安装说明。

5. 在打印机上安装

  1. 确认打印和耗材动作已经结束、加热与烘干关闭、喷嘴和热床低于 50℃。
  2. 把 U 盘插入 U1 的 USB 接口。
  3. 在屏幕依次点 设置 → 关于 → 固件版本 → 本地更新。
  4. 选择 U1_extended_2.0.0-paxx12-24_upgrade.bin。
  5. 按屏幕提示确认更新。
  6. 等待更新结束和机器自动重启。

更新过程中不要拔 U 盘或切断电源。

完成标准： U1 能正常进入主界面，没有升级错误。后面的配置网页还要确认构建版本。

如果列表里没有该文件，先核对文件名、U 盘格式和文件位置。出现升级错误时，记录屏幕文字，按照官方升级故障说明排查；不要反复换随机固件尝试。

四、打开两个不同的访问开关

1. 打开 Advanced Mode

  1. 在 U1 屏幕打开 设置 / Settings。
  2. 点 维护 / Maintenance。
  3. 找到 Advanced Mode，将它开启。
  4. 按要求重启打印机。

完成标准： 回到维护页面时，Advanced Mode 仍为开启状态。扩展配置网页需要这个开关。上游配置说明

2. 打开 Root Access

  1. 再次打开 设置 → 维护。
  2. 点 Root Access。
  3. 阅读页面说明，向下滚动到同意按钮。
  4. 点 Agree / 同意。
  5. 将状态设为 Open。

完成标准： Root Access 页面显示 Open。这是允许安装向导通过 SSH 连接打印机的开关。上游 SSH 说明

Advanced Mode、Root Access 和系统持久化是三件不同的事。前两个需要在这里开启；持久化由本项目安装器处理，不需要你输入 touch 命令。

五、找到打印机地址，并确认电脑能够访问

1. 在 U1 上查看地址

  1. 在打印机屏幕打开 设置 → Wi-Fi。
  2. 确认打印机已经连接你家或工作室的网络。
  3. 找到页面上的 IP 地址 / IP Address。
  4. 把这串带小数点的数字完整记下来。

完成标准： 页面显示已连接，并且有 IP 地址。没有地址时，先选择自己的 Wi-Fi 网络并输入 Wi-Fi 密码。Snapmaker 官方连接检查

固件更新后可能需要重新连接 Wi-Fi。地址也可能变化，请用屏幕现在显示的地址。

2. 让电脑连接同一个家庭网络

电脑和打印机应连接同一个路由器。电脑用网线、打印机用 Wi-Fi 也可以属于同一个家庭网络。

  1. 点击 Windows 右下角的网络图标。
  2. 检查电脑当前连接的网络。
  3. 必要时连接到与打印机相同的家庭网络。

不要把电脑留在手机热点，而让打印机连接另一个网络。Snapmaker 官方网络准备说明

3. 在电脑打开配置网页

  1. 打开 Edge 或 Chrome。
  2. 按 Ctrl + L，选中顶部地址栏。
  3. 输入 http://，后面紧接刚才记下的打印机地址，再接 /firmware-config/。
  4. 按回车键。

不要把地址输入搜索框，也不要把“打印机地址”四个汉字输入网址。

你会看到： 名为 Firmware Config 的配置页面。状态区域会显示基础固件、构建版本等信息。

完成标准： 页面可以打开，构建版本对应 2.0.0-paxx12-24。页面说明

如果打不开，按顺序检查：屏幕 IP 是否变了、Wi-Fi 是否重连、Advanced Mode 是否开启。暂时不要继续主安装。

4. 准备登录密码

安装向导需要的是 SSH 密码，不是 Wi-Fi 密码，也不是 Snapmaker 账号密码。

如果从未修改过 SSH 密码，上游文档列出的用户名是 root，初始密码是 snapmaker。修改过就使用你自己的密码。上游凭据说明

密码输入时，终端可能不显示字符或星号。这不表示键盘没有输入。不要把密码贴到公开问题页面。

六、准备 ACE 到 U1 的硬件连接

软件不能代替正确的线缆。 外形能插入，不代表电气连接正确。

  1. 打开 SnapAce 的 Pinout and Wiring 硬件说明。
  2. 请线缆提供者确认它适用于 ACE Pro 第一代连接 U1 USB。
  3. 确认线缆已经按该硬件方案制作并检查。

上游方案需要专门的 ACE 到 USB 连接。本页不根据线材颜色猜测线序，也不把普通充电线当成成品转接线。

如果你不会看接线图、制作接头或检查线路，请使用经过确认的成品线，或者请有经验的人完成这部分。不要先通电“试试”。

硬件已经准备好以后：

  1. 等喷嘴和热床冷却。
  2. 关闭 U1 和 ACE 的电源。
  3. 按已经核对的硬件方案连接专用 USB 线。
  4. 把 ACE 四路出料管接到对应的 U1 通道。
  5. 核对第 1、2、3、4 路没有交叉接错。
  6. 整理管路，避免压扁、急弯或妨碍打印头移动。
  7. 重新开启设备电源。

完成标准： 接线方案和型号已经确认；四路对应关系清楚；安装向导稍后能够找到 ACE 串口。

如果向导报告“没有找到 ACE”或找到多个候选设备，先检查连接。不要随意选择一个串口继续。

改了 B，但重启后第一次进料仍全程很慢。起点不确定时会用慢速；正常退料完成后的再进料才可能使用新快速段。

每次只改一项长度，调整幅度不得超过能确认的剩余空间。

没有对所有管路都安全的固定步长或比例公式。

换管、缩短管子或重新走管以后

  1. 保存原来正常工作的参数和四槽记录。
  2. 量新路线，更新对应记录。
  3. 重新找四路中最短的有效路径。
  4. 重新校准时先关闭 C。
  5. 下一次进退料前先重新检查 A 和 B。
  6. 重做四路的进料、退料和再进料检查。
  7. 新 A／B 都通过后，再考虑启用 C。

即使只改一根管，共用的 B 也可能不再适合。

不要用旧快速段冲一次，靠是否碰到喷头来判断新管是不是太短。

再启用 C：退料后消松回送

C 把料盘附近松出的线材吸回 PTFE 管，让松圈减小。

它不是单独加速滚筒，也不是检测收紧后自动停止。

它按设定长度向 U1 方向送一段，没有张力传感器终点。

  1. 先确认 C = 0 时四路进料、退料、再进料都正常。
  2. 观察退料后实际留下多少松圈。
  3. 根据松圈和尖端到喷头的余量，选择有限的 C。
  4. forward_takeup_speed 保持不超过 50。
  5. 应用参数后，先对一个槽执行一次正常退料。
  6. 检查喷头仍为空、ACE 入口仍有料。
  7. 不拔出线材，继续检查下一次进料。
  8. 再检查其他三个槽。

300 mm 是已测参考，不是默认推荐给所有用户的数值。

实测记录说明了第 4 槽那次测试的范围。

C 越大，尖端越往喷头方向前进，停留余量越少。

仍有松圈时先确认线材移动顺畅；只有余量明确且未超过限制，才考虑增加 C。

出现过紧、卡住或碰到喷头时停止测试，减小 C 或设为 0。

不要为了抵消过大的 C，又盲目加大 A。

理解两条读卡路径

  1. 耗材 NFC 标签
  2. ACE 读取并解码
  3. U1 查询并转换结果
  4. 显示并保存耗材信息

多品牌解码来自 OpenCubic。U1 内置 OpenRFID 是另一条独立路径。

  1. ACE 的读卡器读取标签，ACE 固件完成标签解码和材料识别。
  2. 运行在 U1 上的适配程序查询 ACE 状态，并通过 get_filament_info 获取该槽的已解码信息。
  3. ACE 返回品牌 brand、耗材类型 type、RGB 颜色 color、sku 和 rfid 状态等字段。
  4. 适配程序统一品牌名称，分开材料类型与细分类型，转换颜色格式，再通过 SET_PRINT_FILAMENT_CONFIG 写入 U1。

这是 U1 查询、ACE 返回识别结果的流程。ACE 不会直接修改 U1 配置；U1 也不在这条路径中解密原始 NFC 标签。

例如，ACE 返回 Bambu Lab、PLA Matte 和 RGB 颜色后，适配程序把它们整理成 Bambu、PLA／Matte 和 U1 使用的颜色值。

这里的 rfid 是识别状态字段，不是供 U1 解码的原始标签内容。

U1 内置读卡器不会通过 USB 去读取 ACE 里面的料卷。

U1 的 OpenRFID 服务使用自己的读卡器和配置文件。

它与 ACE 解码路径独立，在本方案中保持停用。

当前安装器会自动选择 External、禁用 U1 内置读卡路径并停止 U1 的 OpenRFID 服务。

日常进退料与远程操作

日常进料、退料与远程控制

插入耗材

  1. 把耗材插进一个空的 ACE 入口。
  2. 手离开滚筒。
  3. 等待短咬料、预进料和 NFC 识别结束。

送到挤出头

  1. 在 U1 屏幕选择对应打印头。
  2. 点正常“进料”。
  3. 按屏幕提示等待完整动作结束，不重复点击。

退料和消除松圈

  1. 在对应打印头执行正常“退料”。
  2. 等待 U1 先从热端退出材料。
  3. 等待 ACE 回抽设定距离。
  4. 如果启用了回送消松，再等待这段动作完成。
  5. 确认耗材仍留在 ACE 及后方管路内。

只要入口仍有耗材，材料信息就保留。下次直接点进料，无需为了重新识别而拔插。

必须确认

新装默认关闭回送消松；必须校准后启用。

其原理是把耗材朝 U1 方向送回一段，吸收料盘附近的松圈；不是滚筒独立补转，也没有张力传感器。

实测示例是退料 1250 mm / 80 mm/s，再回送 300 mm / 50 mm/s。

这不是适合所有料管的通用参数，调整方法见管路校准。
