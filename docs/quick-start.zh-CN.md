# 新手安装：从这里开始

[English](quick-start.md) · **[中文手动安装](installation.zh-CN.md)**

使用 Windows 10 或 Windows 11 电脑即可。你不需要会编程，不需要安装 Python、Codex 或其他 AI，也不需要 API 密钥。
向导支持 **中文** 和 **English**，会替你输入安装命令。
使用指定 OpenCubic 固件支持的标签，**无需自行寻找或填写 NFC 密钥**。

> [!CAUTION]
> **禁止把旧 SnapAce 的 `filament_feed.py` 或 `extruder.py` 覆盖到 U1 2.0。**
> **本项目替代原 SnapAce 的软件安装步骤。** 上游只参考硬件接线部分。

## 1. 更新或安装之前，先准备设备

1. 等打印及全部进退料动作结束。
2. 第一次安装时，先用正常“退料”退出四个 U1 打印头里的耗材，再将四路耗材退出 ACE 入口。
3. 关闭加热和 ACE 烘干。正常退料可能加热喷嘴；结束后等全部喷嘴和热床低于 50℃。
4. 确认是 **ACE Pro 第一代**，不是 ACE 2 Pro。
5. 准备已核对的 ACE 专用 USB 线和四路料管。连接硬件前关闭两台设备电源；接好后再开机。
6. 让电脑和 U1 连接同一个局域网。两个设备都需要联网访问各自的固件下载地址。
7. 如果 U1 已有自定义改动，更新 U1 固件前先保存私人备份。本项目稍后的备份不能保护发生在它之前的固件更新。

**已有本项目、只是更新：** 不要求把四路耗材全部取出，但设备仍需空闲并冷却。
连接线按 [SnapAce 硬件指南](https://github.com/BlackFrogKok/SnapAce#pinout-and-wiring)准备，不能用普通充电线代替指定转接线。

**打开向导前，不需要另外刷好 ACE 固件。** 向导可以先准备 U1 固件，再检查和准备 ACE 固件。
实际接线，以及 U1 屏幕上的更新与访问开关，仍需要你亲手操作。
屏幕和 U 盘的详细操作见[零基础机器准备指南](before-you-start.zh-CN.md)。

## 2. 下载、解压、启动

1. 点击[下载安装包](https://github.com/Alexantry/Ultimate-U1-ACE-link/raw/refs/heads/main/downloads/Ultimate-U1-ACE-link-v0.1.6.zip)。
2. 打开 Windows 的“下载”文件夹。
3. 右键名称含 `Ultimate-U1-ACE-link-v0.1.6` 的压缩文件，点 **全部解压缩／解压全部**。
4. 点 **提取／解压**，打开解压后的 `Ultimate-U1-ACE-link` 文件夹。
5. 双击 **START-HERE.cmd**。
6. 选择 **1. 中文**。输入选项数字后按回车。

不要在压缩包预览窗口内运行安装程序。
如果 Windows 隐藏后缀，文件可能只显示为 `START-HERE`，类型为 **Windows 命令脚本**。
以 `.html` 结尾的文件是说明页面，不是安装程序。

![下载、解压、双击的示意图](images/first-steps.svg)

**START-HERE.html** 是中文离线手册；**START-HERE.en.html** 是英文离线手册。
使用向导时，不需要双击 Python 文件，也不需要自己打开 PowerShell。
如果想逐条检查并输入命令，使用 **[中文手动安装](installation.zh-CN.md)** 或 **[English manual](installation.md)**。手动方式仍运行可阅读的打印机安装程序。

## 3. 主菜单选哪一个

| 菜单 | 什么时候选 | 接下来会做什么 |
| --- | --- | --- |
| **1. U1 已准备好** | 已有 `2.0.0-paxx12-24`，Advanced Mode 开启，Root Access 为 Open。 | 必要时检查 ACE 固件，再安装或更新 U1 适配。 |
| **2. 准备 U1 固件 U 盘** | 尚未安装指定 U1 固件。 | 下载校验、准备 FAT32 U 盘，再引导屏幕操作；完成后在同一窗口继续。 |
| **3. 手动安装** | 希望使用完整命令说明。 | 打开对应语言的本地手动文档，然后退出，不连接打印机。 |
| **4. ACE 固件** | 只维护 ACE，或查看上次 ACE 更新结果。 | 先查询已有记录，完成 ACE 维护后退出；不会安装 U1 适配。 |

菜单 2 需要一个**已经是 FAT32 格式**的可移动 U 盘，至少空闲 300 MB。
向导不会格式化 U 盘；复制前会让你核对盘符、名称和容量。
屏幕每一步见 [U1 固件准备](u1-preparation.zh-CN.md)。更新后必要时重连 Wi-Fi，IP 地址可能变化。

**自定义或其他版本固件需要单独核对兼容性，不要只为通过安装检查就覆盖。**
本项目要求固定版本，不等于要求上游最新版本。
菜单 4 完成后，如果还需要安装或更新 U1 适配，重新打开向导并选择菜单 1。

## 4. 填写连接信息

| 窗口提示 | 你要输入什么 |
| --- | --- |
| 打印机地址 | U1 的 Wi-Fi 屏幕当前显示的 IP。只填地址，不加 `http://` 或 `/firmware-config/`。 |
| 首次 SSH 连接 | 对照打印机屏幕核对地址，按[首次连接说明](installation.zh-CN.md#confirm-the-connection)处理。已有主机指纹意外变化时停止。 |
| `password:` | 打印机的 SSH root 密码，然后按回车。不是 Wi-Fi 密码，也不是 Snapmaker 账号密码。 |
| 数字选项 | 输入窗口列出的数字，再按回车。 |

上游默认 SSH 用户名是 `root`，初始密码是 `snapmaker`；修改过则用自己的密码。[上游 SSH 说明](https://snapmakeru1-extended-firmware.pages.dev/ssh_access)
**输入密码时没有字符或星号是正常的。** 按正常速度输入完，再按回车。
每次 SSH 连接可能再次要求密码；向导不会保存密码。

## 5. 跟随 ACE 固件步骤

首次安装会自动出现此阶段。
除非你已经确认指定 OpenCubic CFW 1.1.1 已安装且 NFC 正常，否则选择自动检查。
U1 会下载固定镜像，检查大小、SHA-256 和格式，再核对 ACE 身份、源版本和空闲状态。

已实测更新路径为：**ACE Pro 第一代 `V1.3.856`／引导 `V1.0.1` → OpenCubic CFW 1.1.1，运行版本显示 `CV1.3.863`**。
其他源版本不属于当前支持的自动更新路径，不要猜测或强行继续。
单独看到 `CV1.3.863`，也不能证明具体是哪一个社区构建。

核对源版本和目标版本后，再确认一次更新。结果未确认前，保持电源和 USB 连接。
详细提示和断线处理见 [ACE 双语向导说明](ace-wizard.zh-CN.md)。

## 6. 核对初始管路长度，再安装

> [!IMPORTANT]
> **安装器不能测量实际管长或线材张力。**
> **示例距离不是所有机器通用的参数，不要直接照抄。**

第一次安装会询问 A 和 B；已有安装保留当前参数。

![长度和退料后位置的概念图](images/length-guide.svg)

| 字母 | 含义 |
| --- | --- |
| **A** | 从打印头向 ACE 回抽的距离，退完后尖端仍要留在 ACE 及后方料管内。 |
| **B** | 从已知起点开始的快速送料距离，应在到达打印头前结束，且小于 A。 |

按[初次设置与校准步骤](configuration.zh-CN.md#calibrate-the-ptfe-paths)选择适合自己管路的初始值。
安装前完成布局审查与测量，安装后再对四槽逐一实机验证。
已测装置使用 A = 1250 mm、B = 1150 mm，仅供对照。
速度默认值是快速送料 200、接近打印头 50、退料 80。
新装默认关闭退料后的回送消松，正常进退料验证后才启用。

阅读窗口列出的设置；设备检查和初始长度核对通过后，才确认安装。
安装器会备份即将修改的文件，自动设置 **Filament Detection → External**，重启服务并验证生效情况。
选项叫 **External**；`extended` 是固件名称或配置路径中的文字。
这条安装流程不需要配置 U1 内置 OpenRFID，也没有 NFC 密钥填写步骤。

## 7. 等到成功，再逐槽测试

等待窗口明确报告本项目安装成功。
只有 ACE 固件成功的提示，不代表 U1 适配已经安装完成。

1. 向一个空 ACE 入口插入耗材，手离开滚筒。
2. 等短咬料和 NFC 识别结束。
3. 确认没有自动长送到打印头。核对材料信息；未识别的耗材可手动填写。
4. 在 U1 对该槽点 **进料**，等到完成。
5. 点 **退料**，确认耗材仍留在 ACE 内，材料信息也保留。
6. 不拔插耗材，再点一次 **进料**。
7. 这一槽通过后，其余三槽也分别验证，一次只测一槽。

向导不会代替你执行实机测试；四槽共用同一套距离参数。
有卡料、打滑或屏幕报错时停止。日常操作见[使用说明](daily-use.zh-CN.md)，测试边界见[验证记录](validation.md)。

## 某一步停住时怎么办

| 停在哪一步或提示什么 | 怎么处理 |
| --- | --- |
| 提示缺少 OpenSSH 客户端 | 按下面的 Windows 组件步骤安装；不要安装 Python。 |
| 文件上传或连接失败，尚未开始安装 | 核对当前 IP、同一网络、Root Access 和 SSH 密码。 |
| 机器热、忙、烘干或正在使用 ACE | 正常结束动作，关闭加热和烘干，等待温度低于 50℃。 |
| 没有唯一 ACE 接口 | 核对电源、代际和专用线，只连接一台 ACE；不要猜串口。 |
| U1 屏幕固件更新报错 | 停止并保留原文，查看 [U1 固件说明](u1-preparation.zh-CN.md)。这不是主机安装器的文件回退。 |
| ACE 更新没有完整结果，或电脑断线 | 保持电源和 USB。使用同一版本安装包重开向导，选 **菜单 4** 查看已有结果；不要重发更新。 |
| U1 适配安装可能已开始，但没有成功结果 | 保留窗口和诊断文件，不重复安装；按[主机回退说明](update-and-rollback.zh-CN.md)核对备份与服务状态。 |

ACE 固件维护和 U1 主机安装使用不同的恢复路径。
`Automatic rollback VERIFIED` 表示主机文件与服务回退通过，**不表示 ACE 固件已回退**。
不要公开私人配置、凭据或未脱敏的诊断记录。

### Windows 提示缺少 OpenSSH 客户端

1. 点 **开始**，搜索 **可选功能**，打开找到的设置页面。
2. 点 **查看功能** 或 **添加功能**。
3. 搜索 **OpenSSH**，选择 **OpenSSH 客户端**，按页面按钮完成安装。
4. 再次运行 **START-HERE.cmd**。

不要选择 OpenSSH 服务器。受管理的电脑可能需要管理员添加组件。
步骤依据 [Microsoft 的组件说明](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse)。
