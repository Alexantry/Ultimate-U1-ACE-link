# ACE 固件向导

[English](ace-wizard.md) · [新手入口](quick-start.zh-CN.md) · [中文手动安装](installation.zh-CN.md) · [手动刷机参考（英文）](ace-firmware.md)

Windows 向导在安装主机适配之前，先准备 ACE 固件。你不需要输入命令。
固件由 U1 下载，工具也在 U1 上运行，所以 U1 必须能联网访问 GitHub。[这些 NFC 格式](nfc.zh-CN.md)由 OpenCubic 提供，使用它们不需要 NFC 密钥。

> [!IMPORTANT]
> **只适用于 ACE Pro 第一代，不适用于 ACE 2 Pro。**
> **U1 必须先安装指定扩展固件，开启 Advanced Mode，并将 Root Access 设为 Open。**
> **遇到未验证的 ACE 源版本，向导会停止，不会强行刷写。**

## 固件文件

| 用途 | 固定文件 | SHA-256 |
| --- | --- | --- |
| 目标：OpenCubic 第一代 CFW 1.1.1 | `ACE_V1.3.863_20260716.bin`，113720 字节，[发布页 v1.0.2](https://github.com/Jupsi/OpenCubic/releases/tag/v1.0.2) | `95e0b6ddb1e77d624d127ac91d9b3e21caf58adc5e1598faf2be3feacf9b4048` |
| 原厂参考文件 | `ACE_V1.3.863_20250518.bin`，105652 字节，[固定的社区托管文件](https://github.com/Jupsi/OpenCubic/blob/6a97e86eda2872e8f8046cefd9470d89906d9a36/originalFirmware/ACE_V1.3.863_20250518.bin) | `3f3676ba357749b3d0367922cb7f6b0dedc9b3d104c1c29e719ac3e563f5eb63` |

向导下载这些文件，检查大小、SHA-256 和固件格式，通过前不能开始写入。安装包本身不含固件二进制。
原厂文件只是参考，不是从你自己的 ACE 备份出来的固件。**原厂回退还没有经过实机验证，向导不会自动执行回退。**想自己执行这个未验证的高级选项，见[卸载与恢复出厂](restore.zh-CN.md)。

## 支持的起始版本

| 实际检测结果 | 向导的处理 |
| --- | --- |
| 第一代，应用版本 `V1.3.856`，引导程序 `V1.0.1` | 通过全部检查后，可以更新到指定目标。 |
| 已显示 `CV1.3.863` | 不重复刷写；询问你是否已安装指定 OpenCubic 版本，且 NFC 正常。 |
| 其他源版本、引导版本、代际或无法确认身份 | 停止；不猜测、不修改检测结果、不强行启用写入。 |

`CV1.3.863` 这个字符串不能区分所有社区修改版。不知道之前刷了什么时，不要把“已有正确版本”的问题回答为已确认。

## 开始前

1. 等打印和全部耗材动作结束，关闭加热和烘干。
2. 第一次安装本项目时，退出四个 U1 打印头里的耗材，再取出四个 ACE 入口的耗材。只是更新时，不要求清空入口。
3. 等打印机所有加热器降到 50℃ 以下。
4. 连接硬件前关闭两台设备。接好已核对的第一代 ACE USB 连接线和四路料管，再开机。
5. 需要时先完成 [U1 固件准备](u1-preparation.zh-CN.md)。确认 Advanced Mode 已开启，Root Access 为 Open。
6. 维护和重启期间，保持 ACE 电源和 USB 线连接，手离开滚筒。

## 跟窗口操作

1. 完整解压项目压缩包。双击 **START-HERE.cmd**，选择中文或 English。按下表选择任务。
2. 按提示输入打印机当前 IP 地址和 SSH root 密码，填写方法见[连接信息说明](quick-start.zh-CN.md#4-填写连接信息)。
3. 如果存在上次 ACE 更新的记录，先查看结果，再做新的维护。
4. 确认显示的准备条件，然后等待程序下载、校验并检查设备。
5. 核对显示的源版本、引导版本和目标版本，并确认设备是 ACE Pro 第一代。
6. 只有显示的组合正确时，才确认一次固件更新。保持供电，等待验证结果。

| 你的任务 | 主菜单怎么选 | ACE 完成之后 |
| --- | --- | --- |
| U1 已准备好，要安装本项目 | **1. U1 已准备好** | 在同一窗口继续主机适配安装。 |
| 先准备 U1，再安装本项目 | **2. 准备 U1 固件 U 盘** | 完成 U1 屏幕步骤，再继续 ACE 与主机适配安装。 |
| 只维护 ACE，或查询上次 ACE 结果 | **4. ACE 固件** | 完成 ACE 维护；如还要安装主机适配，重新打开向导，选菜单 1。 |

菜单 3 打开所选语言的手动文档，然后退出。更新一旦开始，就在 U1 上继续运行，电脑的 SSH 断开也不影响。

> [!CAUTION]
> **不要因为电脑不再显示进度，就再启动一次更新。**
> **写入期间不要切断 ACE 电源。**
> 使用**同一版本的安装包**重新打开向导，选择菜单 **4** 查看上次结果。
> 已有事务时，这个入口读取保存的结果，不会自动重复写入。

## 怎样才算成功

更新必须得到完整成功结果，才能继续主机安装。如果原来已装好准确固件，走“已确认正确版本”的路径，不要再写入一次。
新的 NFC 解码可能改变品牌、材质或颜色，例如 Generic 变成 Bambu。进入主机安装前，把显示的变化和当前料盘对照。
主机安装完成后，对每个槽做一次有人看护的[进料 → 退料 → 再进料](daily-use.zh-CN.md)检查，一次只测一槽。保留已校准的管长参数。

## 停止或断线后怎么办？

| 提示或情况 | 你该做什么 |
| --- | --- |
| 下载或校验失败 | 检查网络；失败文件不会进入刷写步骤。 |
| 机器正在加热、烘干、打印或使用 ACE | 正常结束对应动作，等待满足条件后再准备。 |
| ACE 版本或设备不受支持 | 保留原固件，保存显示的版本供兼容性核对。 |
| 已显示 `CV1.3.863`，但不知道固件来源 | 不把它确认成指定版本，保持固件不变。 |
| 上次更新仍在运行 | 保持供电，继续查询同一事务。 |
| 电脑断线 | 使用同一版本安装包重开向导查看上次结果，不重复刷写。 |
| 已开始更新，但结果无法确认 | 保持打印控制停止，保留私人记录，按显示的恢复信息处理。 |

结果无法确认的写入不算升级成功，即使已经发送过部分数据。程序不会自动刷原厂包、清空事务或恢复打印。
如果后台任务在**尚未尝试写入固件之前**停止，菜单 **4** 可以提供“仅检查并恢复”的操作。确认一次后等待。它不刷固件；只要曾经尝试写入，就不会提供。
其他情况可能需要[手动维护和恢复（英文）](ace-firmware.md#uncertain-results-and-recovery)。不要修改保存的记录（在打印机的 `/userdata/ultimate-u1-ace-link/ace-firmware/` 目录下）来绕过拒绝条件。
**ACE 固件成功不等于主机适配安装成功**。后面的主机安装失败时，按[主机更新和回退说明](update-and-rollback.zh-CN.md)处理。`Automatic rollback VERIFIED` 只表示主机文件和服务已回退，不表示 ACE 固件已恢复。
还有未处理的固件事务时，新的主机安装和回退都会拒绝运行。不要同时运行旧安装器或独立的手动维护工具。
不要公开设备身份、密码、NFC 密钥或未脱敏的维护日志。
