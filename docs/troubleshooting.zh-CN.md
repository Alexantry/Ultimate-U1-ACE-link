# 故障排查

[English](troubleshooting.md) · [安装向导](quick-start.zh-CN.md) · [日常使用](daily-use.zh-CN.md)

不知道耗材现在停在哪里时，不要连续重复点击进料或退料。
先保持机器空闲，保存完整报错，再按下面对应的情况处理。

> [!IMPORTANT]
> **先区分哪一步出了问题，再选择对应的恢复方法。**
> **电脑断线不代表需要重新刷一次固件。**

| 问题发生在哪一步 | 先做什么 |
| --- | --- |
| U1 屏幕上的固件更新 | 保存屏幕报错，按 [U1 更新故障指引](u1-preparation.zh-CN.md)处理。 |
| ACE 固件更新，或不知道更新结果 | 保持电源和 USB。用同一版本安装包打开向导，选菜单 **4** 查看已有结果。见 [ACE 恢复说明](ace-wizard.zh-CN.md#停止或断线后怎么办)。 |
| U1 主机适配安装 | 查看安装成功或恢复结果；重新安装前先按[主机恢复说明](update-and-rollback.zh-CN.md#after-an-interrupted-installation)核对。 |
| 已安装成功，日常送料、退料或 NFC 不正常 | 按下面检查，不要先重新刷固件。 |

`Automatic rollback VERIFIED` 表示主机文件与服务回退已验证，不表示 ACE 或 U1 固件已经回退。

## 连接和安装

| 看到什么 | 先检查什么 | 下一步 |
| --- | --- | --- |
| SSH 拒绝连接 | Root Access、U1 当前 IP、电脑网络 | 按[首次连接说明](installation.zh-CN.md#confirm-the-connection)核对；电脑与 U1 应在同一局域网。 |
| 输入密码没有字母或星号 | SSH 本来就不显示密码字符。 | 正常输入 root SSH 密码，再按回车；这不是 Wi-Fi 密码。 |
| 找不到 `ssh` 或 `scp` | Windows 缺少 OpenSSH 客户端。 | 按[Windows 组件步骤](quick-start.zh-CN.md#windows-提示缺少-openssh-客户端)安装。 |
| 更新 U1 后找不到机器 | 屏幕 Wi-Fi 是否连接、IP 是否变化 | 重新连接 Wi-Fi，再使用现在的 IP。 |
| 打不开 `/firmware-config/` | Advanced Mode 和当前 IP | 在 U1 开启 Advanced Mode，并按要求重启。 |
| 找不到 ACE，或出现多个串口候选 | ACE 电源、第一代硬件、专用连接线 | 只接一台 ACE。断电检查接线后再做只读检查，不要猜测或随意修改串口路径。 |
| 安装器拒绝某个核心文件 | 文件可能被手动改过，或版本不支持。 | 保留文件和报错，核对迁移方案，不要删除或覆盖来绕过检查。 |
| 安装器拒绝固件版本 | 是否为指定兼容基线 | 保留现有固件，对照 [U1 准备说明](u1-preparation.zh-CN.md)，不要强行通过检查。 |
| 安装器拒绝现有配置 | 是否存在重复或异常 ACE 配置段 | 保存显示的配置路径，核对后再决定修改；不要直接删除其他配置。 |
| 重启后改动消失 | 是否更新过固件、持久化是否保留 | 先读取[安装状态](update-and-rollback.zh-CN.md#read-installation-status)，不要直接重复安装。 |
| Klipper 显示未连接 | `klippy.log` 中的启动错误 | 先恢复后台就绪，再测试进退料。 |

摄像头可能在 Klipper 未连接时仍可观看，因此“有画面”不代表耗材控制已经就绪。

## 送料和退料

| 看到什么 | 含义或检查方向 | 下一步 |
| --- | --- | --- |
| 插入耗材后只短咬料就停住 | 这是预期行为。 | 需要长送料时，在 U1 对该槽点进料。 |
| NFC 识别期间进料等待 | 识别有单独的就绪等待过程。 | 等识别结束，不要反复点进料。 |
| 第二槽等待 | 同一时间由一路操作占用 ACE 输送。 | 等正在执行的操作结束。 |
| 重启后第一次进料较慢 | 软件不能确认线材起点，使用慢速寻料。 | 观察正常进料；出现卡料或错误时停止，不要强行开启快段。 |
| 回送消松后，下次快段变短 | 软件会从快送距离 B 中扣除已回送的距离。 | 按自己的 B、C 核对。1150 − 300 = 850 mm 只是示例。 |
| 进料出现行程或超时错误 | 头端传感器没有确认到料。 | 检查管路与头端传感器，再决定下一步；不要重复长送。 |
| 退料后仍有松圈 | 新装默认关闭回送消松；已有回送距离也可能不足。 | 先确认正常进退料，再按[回送消松校准](configuration.zh-CN.md#enable-forward-take-up)设置。 |
| 退料报错后没有回送消松 | 没有确认正常回抽完成。 | 先处理退料错误。 |
| 退料后耗材仍在 ACE 后方管内 | 这是为下次进料保留耗材的设计。 | 核对 ACE 入口仍有料、打印头已无料。 |
| 收到停止响应后仍短暂动作 | ACE 某些换挡状态不能立即停住。 | 普通进退料测试中动作变得不安全时，关闭 ACE 自身电源。 |

本项目没有独立的滚筒调速参数。回送消松是把线材送入后方 PTFE 管，消耗外面的松圈。
它不检测张力，不单独控制滚筒，也不是把松散线材重新卷回料盘。
示例回送距离不适用于所有管路。

## NFC 和材料显示

| 看到什么 | 检查方向 | 下一步 |
| --- | --- | --- |
| 类型、颜色正常，但品牌是 Generic | 显示是否已经刷新 | 重新打开 U1 该槽详情；仍为 Generic 时核对准确 ACE 构建和标签支持表，保持 External。 |
| U1 有 Bambu，切片软件里没有 | 切片软件自己的品牌和材料预设 | 单独核对切片预设，不要因此改 ACE 固件。 |
| ACE 没有识别标签 | 固件、格式、是否确有原装标签、标签位置 | 对照 [NFC 支持表](nfc.zh-CN.md)；无标签或不支持的料卷可以手填材料。 |
| U1 内置 OpenRFID 能读，ACE 不能 | 两者的读卡器和解码程序不同。 | 检查 ACE 支持路径，不要复制 U1 密钥。 |
| 真正拔出 ACE 入口后材料消失 | 这是预期清除事件。 | 重新插入后等待新的识别。 |
| 只从打印头退料后材料消失 | 材料保留模块可能没有生效。 | 核对本项目安装版本和状态。 |
| 后台没有耗材卡片 | Klipper 状态、网页布局、可用组件 | 先恢复 Klipper 就绪，再比较界面。 |

ACE 路径应使用 **External**。改为内置 OpenRFID 不会升级 ACE 的识别能力。
指定 OpenCubic 固件支持的标签，不需要用户自行寻找或填写 NFC 密钥。

## 只读查看状态，不触发运动

主机安装状态按[状态与连接初始化说明](update-and-rollback.zh-CN.md#read-installation-status)读取。
该说明会确认正确的打印机暂存目录，不要假设以前的 PowerShell 窗口变量仍然存在。
中文连接基础见[手动安装的首次连接步骤](installation.zh-CN.md#confirm-the-connection)。

下面是可选的 ACE 只读状态查询。它读取 U1 网页已有的数据，不发送运动命令，也不另开 ACE 串口。
仅在主机适配已经安装后使用。ACE 固件更新结果未明确时，改用向导菜单 **4**。

1. 按 **Windows 键 + R**，输入 `powershell`，按回车。
2. 复制下面这一行到窗口，按回车。
3. 出现地址提示后，输入 U1 Wi-Fi 屏幕当前显示的 IP；不加 `http://` 或路径，再按回车。

```powershell
$PrinterAddress = (Read-Host "Current printer IP from the Wi-Fi screen").Trim()
```

4. 再复制下面这一段到窗口，按回车。

```powershell
$AceStatus = Invoke-RestMethod "http://$PrinterAddress/printer/objects/query?ace"
$AceStatus.result.status.ace | Format-List
```

没有结果或返回错误时，先检查 Klipper 是否就绪并保存原文，不要修改运动参数来让查询通过。

| 字段 | 怎么看 |
| --- | --- |
| `connected`、`status_fresh` | ACE 是否连接、状态是否新鲜；正常运行时两项都应为 True。 |
| `status`、`last_error` | 当前 ACE 状态，以及最近一次错误。 |
| `gate_status` | 从第 1 到第 4 槽的入口状态：`0` 无料、`1` 有料、`-1` 未知。未知不等于无料。 |
| `fast_origins`、`fast_origin_advance_mm` | 已知进料起点，以及退料后已经向前送过的距离。 |
| `rfid_sync` | 各槽材料信息的同步进度。 |

## 提交问题时保留哪些信息

1. U1 固件完整版本。
2. ACE 代际、运行版本和已知固件来源。
3. 本项目安装版本。
4. 发生问题的槽号。
5. 最后一次正常完成的动作。
6. 分别描述线材和料盘是否移动、何时停止。
7. 报错原文，以及经过检查和脱敏的必要日志片段。

不要上传私人密钥、完整配置备份、密码或未经检查的设备数据。
可在[项目问题页面](https://github.com/Alexantry/Ultimate-U1-ACE-link/issues)报告可以复现的主机适配问题。
